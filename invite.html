Персональная ссылка

Для рассылки по компаниям. По такой ссылке страница поздоровается с компанией по имени и первым покажет нужный концепт, а в игре название компании встанет на площади буквами.

Будет написано так:

Чем занимается
Чем занимается
Куда ведёт ссылка
Куда ведёт ссылка

Подставляется сам, если открыть эту страницу на вашем сайте. Можно вписать свой домен.
